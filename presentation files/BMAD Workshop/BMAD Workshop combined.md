## Slide 3

Image: [Slide3.JPG](Slide3.JPG)

### Slide Content

- Acronyms
- Build More Architect Dreams
- Brian Madiston
- AI-Driven Agile Framework
- Facilitator vs Generator
- Scale-Adaptive Intelligence
- End-to-End Coverage
- Modular

### Notes

- **AI-Driven Agile Framework:** BMAD is an open-source methodology that augments agile software development with AI. It provides specialized AI agents and structured workflows to guide projects of any size. Each agent plays a role in a collaborative "AI team."
- **"Facilitator" vs Generator:** BMAD's agents act as expert collaborators. They guide questioning, structure, and refinement instead of producing one-shot output with little control.
- **Scale-Adaptive Intelligence:** BMAD adjusts planning depth to suit the complexity of the work, from small fixes to enterprise systems.
- **End-to-End Coverage:** It spans the full SDLC and produces just-in-time documentation that leaves an auditable trail.
- **Modular:** The approach extends beyond software delivery into other workflow domains.

### Notes

#### Discovery

The Analyst agent kicks off projects by facilitating idea generation and market research. It acts like an AI business analyst that can run brainstorming workshops, perform competitive analysis, and turn vague ideas into concrete product briefs.

**Validating concepts:** This phase focuses on making sure the team is building the right thing. The Analyst helps refine the project vision and identify risks and requirements early.

### Slide Content

#### Phase 2: Planning

- create-prd
- create-ux-design

### Notes

The Product Manager agent translates business goals into a detailed plan. It helps create PRDs with functional requirements, non-functional requirements, epics, stories, and acceptance criteria.

The AI PM relentlessly organizes detail and asks clarifying questions like a disciplined Product Owner.

**User Experience design:** A UX Designer agent can also contribute in this phase by mapping user journeys and proposing wireframes or design system directions.

## Slide 7

Image: [Slide7.JPG](Slide7.JPG)

### Slide Content

#### Phase 3: Solutioning

- create-architecture
- create-epics-and-stories
- check-implementation-readiness

### Notes

The Architect agent designs the system architecture and technical approach, including system components, data flows, tech stack choices, and ADRs for key decisions.

Because the Architect builds on the PM's outputs, design decisions trace back to the PRD and business needs. That prevents the usual "telephone game" misalignment between planning and implementation.

## Slide 8

Image: [Slide8.JPG](Slide8.JPG)

### Slide Content

#### Phase 4: Implementation

- sprint-planning
- create-story
- dev-story
- automate (QA)
- code-review
- correct-course
- retrospective

### Notes

Before coding starts, the Scrum Master agent transitions the plan into execution by breaking epics into detailed story tasks. Each story file carries context, design guidance, rationale, and test criteria.

**Coding with AI Developer:** The Developer agent implements each story against the specification, using the architecture and acceptance criteria already established. This reduces rewrites and keeps implementation aligned with the design.

**Automated Quality Assurance:** The QA agent validates implemented stories against the original requirements, not just through unit tests but by checking whether the acceptance criteria are actually met.

**Continuous Deployment and DevOps:** BMAD workflows can also support integration testing and CI/CD setup so release steps become more routine and lower risk.
