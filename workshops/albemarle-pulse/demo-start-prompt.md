# Demo Start Prompt

Use this as the opening prompt for the Albemarle Pulse BMAD demo.

## Copy/paste prompt

```text
Albemarle Pulse is a live mobility dashboard centered on the Royal Institution. It combines nearby TfL transport and weather data to show, at a glance, the best options for getting around London from here, what disruption is building next, and how conditions may affect onward journeys. It turns public real-time data into a calm, high-value view for attendees planning what to do next.
```

## Suggested framing

- Start in the analysis stage.
- Ask BMAD to turn this into a product brief and initial research plan.
- Keep the constraints explicit: Royal Institution centered, London only, public data only, calm dashboard rather than full route planning.
