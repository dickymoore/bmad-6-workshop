HarbourWatch Design Directions
Six visual directions built from the Vibrant Maritime foundation. The differences are layout hierarchy, information density, and emphasis; the palette and semantic boundaries stay fixed.
Calm Confidence / Fast Read

Primary source of truth, multiple layout choices

All directions preserve the same tokens, typography, and maritime-industrial mood. The question is which screen anatomy best supports the role-aware waterfront read without drifting into control-room or vessel-tracking semantics.
