HarbourWatch Color Themes

The Vibrant Maritime palette is the source of truth. These swatches map the tokens to semantic use so the board stays calm, readable, and clearly separated from control-room semantics.

Core Palette

Deep Sea Blue
#001629
Primary structure, headings, borders, and shell anchors.
Primary Container
#002b49
Container depth and stable hierarchy surfaces.
Safety Orange
#aa3000
Emphasis, selected role, refresh, and key status markers.
Secondary Container
#d43f00
Supporting accent and active emphasis.
Buoy Red
#ba1a1a
Unavailable, critical failure, or heightened notice state.
Fog White
#f7fafc
Background and calm surface layer.
Primary Text
#181c1e
Main body text and strong content.
Muted Text
#42474d
Source lines, supporting text, and metadata.

Semantic States

Fresh
Normal reading
Use neutral panel treatment with a quiet source line.
Stale
Last known value
Use muted treatment and explicit stale wording.
Unavailable
Source paused
Use Buoy Red sparingly with calm wording.
Fixture-backed
Local fixture
Keep provenance explicit and visible.
The visual rule is simple: use strong color sparingly, keep the board readable, and never let calmness become low contrast or vague status language.
